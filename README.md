# Game Server Backend API 

A lightweight and fast RESTful API built with **FastAPI** and **MySQL** to manage player data for multiplayer game servers (like GTA SAMP/FiveM).

## Features
-  Fetch real-time player statistics directly from the MySQL database.
-  Secure endpoints to update in-game currency, scores, and levels.
-  Modular structure for easy maintenance.

## Tech Stack
- **Language:** Python 3.9+
- **Framework:** FastAPI
- **Database:** MySQL
- **Data Validation:** Pydantic
